## Animation Showcase

### 1. Radar Pulse
```
     ╔═════╗
     ║  ●  ║        ┌─────┐        ┌─────┐
     ╚═════╝   -->  │  ●  │  -->   │  ●  │
                    └─────┘        └─────┘
     Initial        Pulse 1        Pulse 2
     
CSS: @keyframes radar-pulse
Duration: 2s ease-out infinite
Effect: Expanding circle, fading opacity
```

### 2. Grid Scan
```
═══════════════   ═══════════════   ═══════════════
                  ═══════════════
                                    ═══════════════
═══════════════   ═══════════════   ═══════════════

Frame 1          Frame 2           Frame 3

CSS: @keyframes grid-scan
Duration: 3s linear infinite
Effect: Horizontal line moving down
```

### 3. Data Flow
```
    ⚡                 ⚡                 ⚡
                      ⚡                 ⚡
                                        ⚡

Frame 1          Frame 2           Frame 3

CSS: @keyframes data-flow
Duration: 4s linear infinite
Effect: Particles flowing upward
```

### 4. Neon Pulse
```
TEXT  ═══>  TEXT  ═══>  TEXT  ═══>  TEXT
(dim)       (glow)      (bright)    (dim)

CSS: @keyframes neon-pulse
Duration: 3s ease-in-out infinite
Effect: Glowing text intensity
```

### 5. Glitch Effect
```
TEXT  ═══>  T▓XT  ═══>  TE▓T  ═══>  TEXT
(normal)    (shift)     (shift)     (normal)

CSS: @keyframes glitch
Duration: 0.3s infinite
Effect: Random displacement, RGB split
```
